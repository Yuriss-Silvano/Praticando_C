# Exercícios de Programação em C

Repositório dedicado ao armazenamento de exercícios, códigos e práticas desenvolvidas durante meus estudos da linguagem C.

## 📚 Conteúdo desenvolvido

**1. Comandos sequenciais**
- Declaração e utilização de variáveis.
- Tipos de dados.
- Operadores aritméticos.
- Operações e expressões matemáticas.
- Entrada e saída de dados (`scanf` e `printf`).

**2. Estruturas condicionais**
- Estruturas `if` e `else`.
- Estrutura `else if`.
- Estrutura `switch` e `case`.
- Operadores relacionais e lógicos.
- Construção de condições e tomadas de decisão.

**3. Estruturas de repetição**
- Laço `for`.
- Laço `while`.
- Laço `do while`.
- Utilização de contadores e acumuladores.
- Repetições controladas por condições.
